A useful project, end to end

Everyday expense tracking, with the C concepts behind it.

The terminal app combines transaction management with practical summaries and persistent local storage.

Keep a clear record

Add, view, search, update, and delete transactions. Assign each expense a date, category, amount, and payment type.

Set a monthly limit

Manage budgets by month and year. See spending, remaining funds, utilization, and alerts based on saved records.

Understand patterns

Generate daily, monthly, yearly, category, payment method, budget, and high/low expense reports.

Keep data locally

Versioned binary files save expenses, budgets, and custom categories between application sessions.

A real summary, from your records

See the month without doing the math by hand.

The dashboard calculates its values from the transactions you enter. It can show lifetime and current-month spending, the selected monthly budget, remaining amount, utilization, transaction counts, and spending highlights.

  • ✓Budget alerts reflect the selected month’s spending.
  • ✓Search by ID, date, category, payment method, amount, or description.
  • ✓Sort and filter a working copy without changing saved records.

Small, focused C modules

Organized so the code is easier to follow.

Headers share the project’s types and function declarations; each source module owns a clear responsibility.

Startup, menu dispatch, cleanup

expense.c

Transactions, search, sorting, categories

budget.c

Monthly budgets and calculations

reports.c

Summaries and text export

Versioned file loading and saving

Bounded input and conversion checks

Calendar dates, leap years, comparisons

ui.c

Menus, dashboard, table presentation

The project demonstrates structures, enums, pointers, dynamic arrays, file handling, and a tagged union for optional payment details.

Get it running

Build it in a few commands.

Download and extract the project, open a terminal in its folder, then compile and launch the menu-driven C application.

Requirements
GCC with C11 support and GNU Make (or a compatible toolchain).
macOS / Linux / compatible terminal
1

Open the extracted project folder.

cd Student-Expense-Tracker
2

Compile the C source files.

make
3

Start the expense tracker.

make run
4

Run the included automated checks when needed.

make test
